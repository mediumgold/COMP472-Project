Overview
In this project, you will investigate how different Artificial Intelligence algorithms behave across two different types of data:

Visual object recognition
Natural-language sentiment analysis
Instead of working directly with raw images or raw text, you will work with pre-extracted numerical feature vectors. For the visual task, each image has already been passed through a feature extractor and is represented by a fixed-dimensional vector. For the sentiment task, each text sample has already been passed through a pretrained language encoder and is also represented by a fixed-dimensional vector. You are not expected to train the feature extractors. You are expected to implement, compare, analyze, and explain multiple AI algorithms covered in the course. You will investigate different questions such as:

How do different classifiers behave on different types of representations?
Does an algorithm that performs well on visual features also perform well on language features?
How sensitive are algorithms to their hyperparameters?
How well do the feature representations naturally separate the classes?
When does a more complex model provide a meaningful improvement over a simpler one?
What kinds of examples are difficult for each model?
Your final Kaggle score contributes to the performance component of the project. However, the majority of the project grade is based on your analysis, understanding, report, and presentation.

Example Submission Code
The following example assumes that you have generated predictions for both test datasets, in the same order as their corresponding test CSVs.

import pandas as pd

image_test = pd.read_csv("image_test.csv")
sentiment_test = pd.read_csv("sentiment_test.csv")

sample = pd.read_csv("sample_submission.csv")

# Predictions generated by your models.
# image_predictions: one prediction per image test row
# sentiment_predictions: one prediction per sentiment test row

image_results = pd.DataFrame({
    "id": image_test["id"],
    "label": image_predictions
})

sentiment_results = pd.DataFrame({
    "id": sentiment_test["id"],
    "label": sentiment_predictions
})

# Combine predictions from both tasks.
predictions = pd.concat(
    [image_results, sentiment_results],
    ignore_index=True
)

# Match predictions to the submission IDs.
submission = sample[["id"]].merge(
    predictions,
    on="id",
    how="left",
    validate="one_to_one"
)

# Validate predictions.
assert len(submission) == 10000
assert submission["label"].notna().all()

submission["label"] = submission["label"].astype(int)

image_mask = submission["id"].str.startswith("img_")
sentiment_mask = submission["id"].str.startswith("text_")

assert submission.loc[
    image_mask, "label"
].between(0, 49).all()

assert submission.loc[
    sentiment_mask, "label"
].between(0, 2).all()

submission.to_csv("submission.csv", index=False)
Upload submission.csv to Kaggle using Submit Predictions.
